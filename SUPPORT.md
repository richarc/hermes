# Support

**Questions** about using Hermes Editor — setup, citations, charts, export,
anything of the "how do I…?" kind — go to
[Q&A in Discussions](https://github.com/richarc/hermes/discussions/categories/q-a).
Check the [guides](https://www.hermeseditor.com/guides) first; if they do not
cover it, ask, and the maintainer will answer.

**Bugs** — something that did not behave as expected — go through the
[bug report form](https://github.com/richarc/hermes/issues/new?template=bug_report.yml),
or Help → Report an Issue… inside the editor, which opens the same form with
your version filled in. **Ideas** for features and improvements go to
[Ideas in Discussions](https://github.com/richarc/hermes/discussions/categories/ideas),
where you can also upvote the ones already proposed.
